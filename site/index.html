Monocle GitHub

A Markdown editor for your agents' files.

Agents write plans, notes and instructions as .md files. Monocle opens the folder so you can read and edit them.

Download Monocle

Mac with Apple silicon.

  • Your agents' files, in one place

    Pick the folder your agents work in. Monocle lists every .md file in it, from plans and notes to AGENTS.md, and a refresh brings in what they wrote since. Press ⌘P to jump to any file.

    Image placeholder
    Your agents' files, in one place

  • Plain files, nothing in between

    There is no database, no sync service and no format of its own. Your agents and every other tool read and write the same .md files Monocle edits.

    Image placeholder
    Plain files, nothing in between

  • Edits that stay valid Markdown

    Change a plan in blocks, with headings, to-dos, tables and code. Every block and mark survives a save, so the file stays readable to the agent that wrote it.

  • Set it up your way

    Light, dark or system, with a tinted page and a column width you set yourself. Walk the tree with the arrow keys.
